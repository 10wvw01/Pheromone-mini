## 阅读建议

1. 先阅读主文档，确认本期边界和三层调度定义。
2. 再阅读第 1～3 章，掌握 Pheromone 设计继承与总体架构。
3. 重点阅读第 8～10 章，理解事件触发、Task 还原和三级调度。
4. 阅读第 11～14 章冻结 Data SDK 与 Task Coroutine Pool 的接口。
5. 最后通过第 19～21 章确认功能范围、验收标准和研发顺序。

## 文档约定

- “P0 / 本期实现”表示 Demo 必须具备。
- “P1 / 建议实现”表示本期可选，需结合工期和上下游能力决定。
- “预留”表示只定义扩展边界，不在本期编码。
- “待接口冻结”表示本文给出了推荐契约，但需要与对应团队评审确认。
- Pheromone 源码描述以附录 A 所列 commit 为准；自研设计决策与源码事实分开表述。
